# CPPAudioMixer

CPPAudioMixer est un logiciel C++ pour le mixage audio, conçu pour être performant et facile à utliser et intégrer.

## Fonctionnalités

- Mixage de plusieurs flux audio
- Support des formats PCM 16 bits et flottant
- API simple et moderne en C++
- Compatible avec CMake (générateur Ninja)
- Testé avec CMake 3.31.6-msvc6 (minimum requis : 3.8)

## Installation

1. Clonez ce dépôt
2. Générez avec CMake
